## 📖 О проекте

**Agent for Phaser** — это автоматизированный пайплайн, который превращает минимальное описание игры в рабочий прототип на **Phaser 3** (TypeScript) с интеграцией платформы **Яндекс Игр** (YSdk).

Проект использует **четыре AI-агента** (вдохновлённых подходом AutoGPT) для последовательного выполнения этапов:

1. **Генератор концепции** — создаёт идею игры, механику, монетизацию и целевую аудиторию.
2. **Дизайнер игры** — прорабатывает сцены, объекты, физику, UI/UX и визуальный стиль.
3. **Генератор кода** — пишет TypeScript-код для Phaser 3 с учётом всех ограничений (мобильные устройства, Яндекс Игры).
4. **Ревьюер / Автофикс** — проверяет код на ошибки, исправляет их и оптимизирует.

Агенты могут пользоваться **веб-поиском (Tavily)** для получения актуальной документации Phaser и примеров.

## ✨ Возможности

- 🧠 **Мультиагентная архитектура** — каждый этап выполняется специализированным ИИ-агентом.
- 🔄 **Автоисправление ошибок** — ревьюер анализирует код и предлагает правки.
- 🌐 **Веб-поиск** — агенты могут искать документацию и решения в реальном времени.
- 🎯 **Готовность к Яндекс Играм** — генерация кода с учётом YSdk, монетизации (реклама, покупки), мобильной адаптации.
- 📊 **Треккинг лимитов API** — контроль использования OpenRouter и Tavily.
- 💓 **Heartbeat-индикатор** — показывает, что процесс работает, даже на длительных запросах.
- ⚡ **Поддержка OpenRouter** — автоматический выбор бесплатных моделей через `openrouter/free`.

## 🚀 Быстрый старт

### Требования
- Node.js **18+**
- npm или yarn
- API-ключи:
  - [OpenRouter](https://openrouter.ai/) — для доступа к LLM.
  - [Tavily](https://tavily.com/) — для веб-поиска (опционально, но рекомендуется).

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/Kolobokoleg29/Agent_for_phaser.git
cd Agent_for_phaser

# Устанавливаем зависимости
npm install
Настройка окружения
Скопируйте пример конфигурации и заполните свои ключи:

bash
cp .env.example .env
Отредактируйте .env:

env
OPENROUTER_API_KEY=ваш_ключ_здесь
TAVILY_API_KEY=ваш_ключ_здесь   # если используете поиск
# Другие параметры (при необходимости)
Запуск
Все команды выполняются через npm-скрипты (см. package.json):

bash
# Запуск полного пайплайна (концепция → дизайн → код → ревью)
npm run pipeline

# Генерация только концепции
npm run brainstorm

# Запуск только генерации кода (на основе готовой концепции)
npm run codegen

# Проверка и автофикс кода
npm run review
💡 Совет: Для первого запуска используйте npm run pipeline — вам будет предложено ввести описание игры в интерактивном режиме.

🧠 Как это работает (подробно)
Ввод пользователя — вы описываете идею игры (например: "аркада, где надо уклоняться от падающих блоков").

Генерация концепции — агент-концептолог создаёт расширенную спецификацию:

Жанр, механики, целевая аудитория.

Монетизация (реклама, внутриигровые покупки).

Ограничения по платформе (Яндекс Игры, мобильные устройства).

Дизайн игры — второй агент прорабатывает технический дизайн:

Сцены (загрузочная, меню, игровая, финишная).

Объекты (игрок, враги, препятствия, бонусы).

Физика, анимации, звуковое сопровождение.

Структура кода (классы, файлы).

Генерация кода — третий агент пишет TypeScript-код на Phaser 3, используя:

Шаблоны и паттерны, описанные в дизайне.

Актуальную документацию (через веб-поиск, если нужно).

Интеграцию с YSdk (реклама, покупки, сохранения).

Ревью и автофикс — четвёртый агент анализирует код:

Проверяет на синтаксические ошибки (через tsc --noEmit).

Ищет логические несоответствия.

Исправляет найденные проблемы (самостоятельно или предлагает правки пользователю).

Сборка и запуск (планируется) — автоматическая сборка через Vite и запуск dev-сервера для тестирования игры в браузере.

🛠️ Технологии
TypeScript — основной язык.

Phaser 3 — игровой движок.

OpenRouter — унифицированный доступ к LLM (поддерживаются GPT-4o, Claude, Gemini и др.).

Tavily — API для поиска по документации.

Vite — сборка (в планах).

YSdk — SDK для публикации игр на Яндекс Играх.
